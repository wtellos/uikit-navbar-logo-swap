# Yootheme-navbar-logo-swap
Replaces the logo on scroll and styles nav items if is homepage.

# Usage
1. Upload a secondary logo in Yootheme builder -> Layout -> Site -> Inverse Logo (Optional)
2. Select 'Make header transparent' in Yootheme builder -> Layout -> Header
3. Added CSS animation (Flashing of Unstyled Content) since CSS is parsed before JS executes.
4. Add the js script on Yootheme builder -> Settings -> Scripts
